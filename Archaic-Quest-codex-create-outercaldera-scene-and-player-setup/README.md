# Archaic Quest

Archaic Quest is a combat-first systemic MMORPG concept currently being built as a single-player local vertical slice prototype.

## Current Build Target

**Vertical Slice V1:** Ashen Scar — Outer Caldera

The first playable build is intentionally narrow. It must prove combat weight, readable enemy roles, behavior-driven weapons, crafting tradeoffs, death tension, and a visible world-state consequence loop before any broader MMO features are added.

## Slice Scope

- Region: Ashen Scar — Outer Caldera
- Settlement: Cinderford Watch
- Classes: Barbarian, Archer, Mage
- Weapons: 2 per class
- Enemy roles: Bruiser, Skirmisher, Support
- Elite modifier: Ash-Parasite Infested
- Mini-boss: The Forgemouth Parasite
- Crafting: 1 bench, 6 materials, 4 mods
- Territory node: Blackglass Watchpost
- Dungeon route: Hollow Vent Approach

## Production Rule

If combat degrades, stop expansion and fix combat first.
